Call Desk（AI 自動架電・テレアポツール）

商材ごとに学習したAIが、架電リストに順番に電話をかけて、受付突破からアポ獲得まで会話するテレアポツール。かける前にブラウザで自分がお客様役になって試せる。

01 / Challenge · 解決したいこと

テレアポは件数が必要なのに、断られ続ける負担が大きく、話し方も人によってばらつく。商材ごとの「売れるトーク」を、誰でも同じ品質でたくさんの架電に使えるようにしたい。

02 / Built · 作ったもの

商材と説明資料を登録すると、AIがその商材専用の台本（プレイブック）を作る。人が中身を確認して有効にすると、AIが架電リストに順番に電話をかけ、ヒアリング・切り返し・日程調整まで自分で会話する。

  • 台本づくり：説明資料（テキスト・PDF）、人の営業の通話分析、受注した通話、過去のAI架電の結果から、商材専用の台本をAIが作成
  • 架電リストは Excel や CSV をそのまま取り込み、時間帯・最大回数・同時に話す本数を決めて自動で架電
  • 冒頭でAIであることと録音を伝え、相づちでは止まらず、相手が話し始めたら止まって聞く
  • 2回断られたら引き下がり、「電話しないで」と言われた番号は架電停止リストに登録
  • ロールプレイ：電話をかける前に、自分がお客様役になって声か文字でAIと話して試せる

Screens · 実際の画面

03 / Stack · 使った技術

画面は Next.js（App Router）/ React / TypeScript / Tailwind CSS。会話は Claude API（ストリーミング応答と、日程提示・アポ登録・担当者への転送・資料検索などのツール呼び出し）。電話は Twilio Media Streams、音声認識は Deepgram、音声合成は ElevenLabs。資料検索は OpenAI Embeddings と pgvector。データとログインは Supabase で、通話は常時起動の Node.js ワーカーが処理する。

04 / Result · 成果と工夫

ログイン画面の「ログインせずにゲストとして使う」から、サンプルデータの全画面を誰でも操作できます（スマホ対応）。デモのAIは台本どおりに進む簡易版で、本番では Claude が応答します。Sales Desk と同じデータベースを使う姉妹アプリです。
